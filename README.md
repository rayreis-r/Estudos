# Dados & Analytics 

> *Aprenda Python do zero ao avançado no seu próprio ritmo!* ✨

---

Eaiii Pessoal! 

O intuito desse repositório é criar um espaço acolhedor e prático para ajudar qualquer pessoa que esteja iniciando (ou queira evoluir) na carreira de **Dados e Analytics**. 

A ideia é construirmos uma jornada leve, cobrindo assuntos desde a sintaxe básica de **Python** até tópicos avançados de análise, tratamento e modelagem de dados. Conforme formos evoluindo nos conteúdos, também traremos exercícios práticos com resoluções para você fixar tudo o que aprender! 

---

-  **Explicando Conceitos:** Teoria direto ao ponto, com exemplos do mundo real.
-  **Exercícios Práticos:** Atividades para colocar a mão na massa.
-  **Resoluções Passo a Passo:** Para você conferir seu raciocínio sem mistério.
